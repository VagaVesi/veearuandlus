# Andmepõhise aruandluse (APA) veearuandlus näited

Prototüüp, mis ilmestab kuidas võiks veearuandluse andmeid esitada.

**Aruandlusvajadus**, mida prototüüp võiks katta:
- [ ] Vee erikasutusõiguse deklaratsiooni jaoks andmed
- [ ] Veesaastetasu deklaratsiooni jaoks andmed
- [ ] Vee seirearuannete andmed
- [ ] Veehinna taotluse jaoks alusandmed

**Veeteenuste hinnataotluse jaoks alusandmed** jagunevad omakorda alljärgnevalt
- [ ] Veehinnaga seotud detailsed kulud (tuhandetes eurodes) kululiikide lõikes. Andmed tuleb esitada eri aastate lõikes.
- [ ] Kokku ostetud veeteenuste kogus ja summa 
- [ ] Veeteenuseks ostetud elektriteenuste(kulude) kogus ja summa
- [ ] Müüdud kogus ja summa teenuste (joogivesi, reovee puhastamine) lõikes. Andmed tuleb esitada eri aastate lõikes.
- [ ] Andmed Müüdud teenuste koguste kohta tegevuspiirkondade lõikes. Andmed tuleb esitada eri aastate lõikes.
- [ ] Andmed põhivarade kohta (põhivarade arv liikide lõikes nt pumplate arv, torustike pikkus jne). Andmed tuleb esitada eri aastate lõikes.
- [ ] Laenukohustuste info seoses investeeringutega (laenukohustuse määr, tagasimakse summad). Andmed tuleb esitada eri aastate lõikes.
- [ ] Vee saastenäitajate kogused aastate lõikes eristatuna, mis on kaetud keskonnaloaga ja mis mitte.
- [ ] Investeringud teenuste lõikes. Andmed tuleb esitada eri aastate lõikes (nii ajaloolised andmed kui tulevikus plaanitavad)
- [ ] Põhivarade liigumine varagruppide lõikes. Andmed tuleb esitada eri aastate lõikes

Sisaldab:
- Klassifikaatoreid, mida andmete esitamiseks vaja
- Andmekosseisude kirjeldusi (andmesektsioonid ja nende struktuur)
- Näidisfaile (XBRL GL vormingus)
